# Sistema-Gestao-de-Casas-Inteligentes

No âmbito na disciplina de Programação Orientada aos Objetos foi desenvolvida uma plataforma intitulada DomusControl, focada na simulação e gestão de um ambiente de Smart Home.
Neste contexto, o objetivo principal deste projeto consistiu em criar um sistema robusto e escalável capaz de administrar múltiplas casas, as suas respetivas divisões e uma vasta gama de dispositivos inteligentes, desde Lâmpadas, Colunas de som, Reles, Cortinas, Portões de
Garagem e Tomadas.
Para além da gestão física do espaço, o sistema foi desenhado para suportar a interação de diferentes perfis de utilizadores (com privilégios de Administrador ou Utilizador comum) e permitir a criação e implementação de automações, de cenários e escalonamentos, conferindo autonomia e inteligência à habitação.
Foi desenvolvida um menu interface para permitir o aos utilizadores operar sobre os dispositivos existentes ou criar novos, e ainda definir automações, escalonamentos e cenários.
É possível ainda obter informações sobre o sistema através do uso dos métodos estatísticos
acessíveis pelo menu.
